# pixelverde
Infraestructura en contenedores para el sitio de portafolio del Estudio Pixel Verde (TYPO3 + MariaDB, Docker Compose, BIND9, Apache HTTPS). Proyecto EIF431O · UNA · Grupo Nodos.
Un solo docker-compose.yml para que TYPO3 funcione igual en cualquier máquina. Escenario 6 del proyecto de EIF431O, UNA Campus Nicoya.
